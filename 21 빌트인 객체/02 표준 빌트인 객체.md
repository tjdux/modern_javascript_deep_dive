## 표준 빌트인 객체

- `Math`, `Reflect`, `JSON`을 제외한 표준 빌트인 객체는 모두 인스턴스를 생성할 수 있는 생성자 함수 객체

### 생성자 함수 객체가 아닌 표준 빌트인 객체

- 정적 메서드만 제공

### 생성자 함수 객체인 표준 빌트인객체

- 프로토타입 메서드 & 정적 메서드 제공

```js
// 1️⃣ String
const strObj = new String("Park"); // String {"Park"}
console.log(typeof strObj); //object

// 2️⃣ Number
const numObj = new Number(123); // Number {123}
console.log(typeof numObj); //object

// 3️⃣ Boolean
const boolObj = new Boolean(true); // Boolean {true}
console.log(typeof boolObj); //object

// 4️⃣ Function
const func = new Function("x", "return x*x"); // f anonymous(x )
console.log(typeof func); // function

// 5️⃣ Array
const arr = new Array(1, 2, 3); // (3) [1, 2, 3]
console.log(typeof arr); // object

// 6️⃣ RegExp
const regExp = new RegExp(/ab+c/i); // /ab+c/i
console.log(typeof regExp); // object

// 7️⃣ Date
const date = new Date();
console.log(typeof date); //object
```

- 인스턴스의 프로토타입은 표준 빌트인 객체의 prototype 프로퍼티에 바인딩된 객체

```js
const strObj = new String("park");
console.log(Object.getPrototypeOf(strObj) === String.prototype); // true
```

- 표준 빌트인 객체의 prototype 프로퍼티에 바인딩된 객체 (e.g. `String.prototype`)는 다양한 기능의 프로토타입 메서드 & 빌트인 정적 메서드를 제공
  - 프로토타입 메서드는 인스턴스가 상속을 통해 사용 가능

```js
const numObj = new Number(1.5); // Number {1.5}

// toFixed: Number.prototype의 프로토타입 메서드
console.log(numObj.toFixed()); //2

// Numer.isInteger: Number의 정적 메서드
console.log(Number.isInteger(0.5)); //false
```
