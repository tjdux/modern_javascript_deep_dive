## 정적 프로퍼티 / 메서드

- 생성자 함수로 인스턴스를 생성하지 않아도 참조 / 호출할 수 있는 프로퍼티 / 메서드
- 생성자 함수가 소유한 프로퍼티 / 메서드
- 생성자 함수가 생성한 인스턴스로 참조 / 호출 불가

```js
// 생성자 함수
function Person(name) {
  this.name = name;
}

// 프로토타입 메서드
Person.prototype.sayHello = function () {
  console.log(`Hi! My name is ${this.name}`);
};

// 정적 프로퍼티
Person.staticProp = "static prop";

// 정적 메서드
Person.staticMethod = function () {
  console.log("staticMethod");
};

const me = new Person("Park");

Person.staticMethod(); //staticMethod
me.staticMethod(); // TypeError: me.staticMethod is not a function
```

- 정적 프로퍼티 / 메서드는 인스턴스의 프로토타입 체인에 속한 객체의 프로퍼티/메서드가 아니므로 인스턴스로 접근 불가
- `Object.prototype.hasOwnProperty` 메서드는 모든 객체의 프로토타입 체인의 종점인 `Object.prototype`의 메서드이므로 모든 객체가 호출 가능
- 만약 인스턴스/프로토타입 메서드 내에서 `this`를 사용하지 않는다면 그 메서드는 정적 메서드로 변경 가능

```js
function Foo() {}

// this를 사용하지 않는 프로토타입 메서드
Foo.prototype.x = function () {
  console.log("x");
};

const foo = new Foo();
foo.x(); //x

Foo.x = function () {
  console.log("x");
};

Foo.x(); //x
```
